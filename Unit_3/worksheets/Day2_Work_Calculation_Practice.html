Part A: Horizontal Forces & Zero-Work Direction Traps (Problems 1–4) All Periods Complete #1–#4
#1FADED EXAMPLE A student pushes a lab cart forward across a flat table with a horizontal force of 45 N over a displacement of 6.0 m. Calculate the mechanical work done.
Given: F = 45 N   |   d = 6.0 m   |   Unknown: W = ? (J)
Equation: W = F · d
Substitute: W = ( 45 N ) · ( m )
Same direction → (+ / − / 0) W = J
#2REVERSE SOLVE A warehouse forklift applies a steady 120 N horizontal push and transfers 600 J of mechanical work to a crate. How far did the crate move?
Given: W = _________   |   F = _________
Equation: d = W ÷ F
Substitute: d = ( _______ J ) ÷ ( _______ N )
Show division clearly d = m
#3OPPOSING FORCE Bicycle brakes apply a constant 400 N backward force opposing forward motion while skidding 8.0 m to a stop. Find the braking work (include sign!).
Given: F = −400 N (opposes motion)  |  d = 8.0 m
Equation: W = F · d
Substitute: W = ( ________ ) · ( ________ )
Adds or removes? ________ W = J
#4DIRECTION TRAP A student carries a 15 kg instrument case (Fg = 150 N upward carry force) at constant height across a flat 20 m hallway. Find the work done by the carry force.

Reason: ____________________________________

Part B: Vertical Lifting Work Against Gravity · W = m · g · h (Problems 5–8) Use g = 10 m/s² Always
#5BENCH LIFT A student lifts a 4.0 kg medicine ball straight up onto a 1.5 m shelf at steady speed. First find its weight Fg, then find the lifting work W.

Equation: W = Fg · h
Substitute: W = ( _______ N ) · ( _______ m )
Check: m · g · h match? W = J

Weight: Fg = ( _____ kg )( 10 m/s² ) = ______ N
Equation: W = Fg · h
Substitute: W = ( _______ N ) · ( _______ m )
1 kilojoule = 1,000 J W = J

#7REVERSE HEIGHT A 60 kg rock climber performs 12,000 J of vertical lifting work climbing a cliff wall (g = 10 m/s²). How high did the climber ascend?
Step 1 — Weight: Fg = 60 kg · 10 m/s² = __________ N
Step 2 — Height: h = W ÷ Fg
Substitute: h = ( 12,000 J ) ÷ ( _________ N )
Check: Fg · h = 12,000 J? h = m
#83-STAGE PATH A worker carries a 10 kg box (Fg = 100 N) in three stages: (a) lifts it straight up 1.2 m, (b) walks 8.0 m across a flat floor, then (c) lifts it another 0.80 m onto a shelf.
(a) Lift: Wa = _____ N · _____ m = _______ J
(b) Walk: Wb = ______ J (Why: ______________)
(c) Lift: Wc = _____ N · _____ m = _______ J
Wtotal = Wa + Wb + Wc Wtotal = J
Part C: Net Work, Multi-Force Systems & Challenges (Problems 9–12) Watch Opposing Signs
#9NET WORK Two students push a heavy sled 10 m east with Fpush = 120 N east while snow friction opposes with Ff = 40 N west. Find Wpush, Wf, and Wnet.
Push: Wpush = ( +120 N ) · ( 10 m ) = ________ J
Friction: Wf = ( −40 N ) · ( 10 m ) = ________ J
Net Force: Fnet = 120 − 40 = ______ N
Wnet = Wpush + Wf = Fnet · d Wnet = J
#10CP BONUS / P0 REQ. You pull a rolling suitcase 15 m horizontally across an airport concourse using a 40 N strap angled 60° above the floor (Fx = F · cos 60°, where cos 60° = 0.50).
Step 1 — Forward Component:
Fx = ( 40 N ) · ( 0.50 ) = __________ N
Step 2 — Work: W = Fx · d = ( _____ N ) · ( 15 m )
Only parallel component does work! W = J
#11HONORS / DETECTIVE A worker pushes a crate forward with Fpush = 90 N over 10 m, but the measured net work on the crate is only Wnet = +650 J. Find the friction work Wf and friction force Ff.
1. Push: Wpush = ( 90 N )( 10 m ) = ________ J
2. Friction: Wf = Wnet − Wpush = ________ J
3. Force: Ff = |Wf| ÷ d = ________ ÷ 10 m
Wf = ______ J Ff = N
#12PATH COMPARISON Compare moving a 20 kg crate (g = 10 m/s²) two ways: Path 1: lift straight up 4.0 m; Path 2: push steadily 4.0 m flat against floor friction (Ff = 50 N). Which takes more work?
Path 1: Fg = ____ N → W1 = ____ · 4.0 = _____ J
Path 2: Fpush = 50 N → W2 = 50 · 4.0 = _____ J
Ratio: Vertical lift requires ____× more work!
Larger path: ________ ΔW = J
