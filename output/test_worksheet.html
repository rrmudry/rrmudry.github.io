Problem 1

Guided Scaffold

A 4.0 kg cart is pulled across a smooth laboratory track by a horizontal tension cable. Friction between the cart wheels and track is negligibly small.

Extracted Givens
  • Mass (m) = 4.0 kg
  • Horizontal Tension (F_T) = 12.0 N
  • Friction force (F_f) = 0 N
[Diagram: Cart on horizontal track pulled to the right by tension F_T with vertical normal force F_N and gravity F_g balanced.]
F_N (up) • F_g = 39.2 N (down) • F_T = 12.0 N (right)

Teacher Solution (2 steps):
  1. Draw upward normal force arrow F_N and downward gravity arrow F_g equal in length.
  2. Draw rightward horizontal tension arrow F_T = 12.0 N with no opposing friction arrow.
☐ (b) Calculate Determine the horizontal acceleration of the cart assuming zero friction.
1. Symbolic Setup
a = F_net / m
2. Substitution & Evaluation
a = ( 12.0 N ) / ( 4.0 kg ) =

Teacher Solution (3 steps):
  1. Identify F_net = F_T = 12.0 N.
  2. Rearrange formula: a = F_net / m.
  3. Substitute values: a = 12.0 N / 4.0 kg = 3.0 m/s².

Problem 2

A student pushes an 8.0 kg wooden crate across a rough linoleum floor with a steady horizontal force of 38.0 N. Kinetic friction opposes the motion.

Extracted Givens
  • Mass (m) = 8.0 kg
  • Applied Force (F_app) = 38.0 N (right)
  • Friction Force (F_f) = 14.0 N (left)
[Diagram: Crate on floor with forward applied push and backward opposing friction.]
F_app = 38.0 N • F_f = 14.0 N • m = 8.0 kg
☐ (a) Calculate Determine the net horizontal force (F_net) acting on the crate in the direction of motion.
1. Vector Sum Setup
2. Calculation
[ N ]
Teacher Solution (2 steps):
  1. F_net = F_app − F_f
  2. F_net = 38.0 N − 14.0 N = 24.0 N
☐ (b) Calculate Calculate the resulting horizontal acceleration of the crate while the push is applied.
1. Symbolic Formula
2. Value Substitution & Answer
[ m/s² ]
Teacher Solution (3 steps):
  1. Use Newton's 2nd Law: a = F_net / m
  2. Substitute: a = 24.0 N / 8.0 kg
  3. Evaluate: a = 3.0 m/s²
☐ (c) Explain Explain what happens to the crate's acceleration if the student doubles the applied push to 76.0 N while friction remains 14.0 N.
Scientific Explanation (Claim & Evidence)
Teacher Solution (3 steps):
  1. State new net force: F_net = 76 N − 14 N = 62 N.
  2. Note that F_net more than doubles (from 24 N to 62 N, a 2.58x increase).
  3. Conclude that acceleration increases by more than double (a = 62 / 8 = 7.75 m/s²).
