Theory Primer: Vector Mathematics & Cartesian Deltas

How to compute displacement vectors from (x, y) coordinates using the Pythagorean Theorem.

1. Coordinate Differences (Δx, Δy)

For any vector from P₁(x₁, y₁) to P₂(x₂, y₂):

Δx = x₂ − x₁ (East / West)
Δy = y₂ − y₁ (North / South)

Moving West or South produces negative (−) component values!

2. The Pythagorean Theorem

Because Δx and Δy are perpendicular (meet at 90°), the displacement vector Δr forms the hypotenuse:

|Δr| = √(Δx² + Δy²)

Real Distance = |Δr| (cm) × Realm Scale Factor (leagues/cm).

3. Component Addition (Net Resultant)

To find the overall displacement from start to finish across multiple turns:

Δx_net = Δx₁ + Δx₂ + Δx₃
Δy_net = Δy₁ + Δy₂ + Δy₃
|Δr_net| = √(Δx_net² + Δy_net²)
