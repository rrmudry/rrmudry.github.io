Key Takeaway: Constant Speed

A horizontal flat line means velocity does not change. Acceleration is 0 m/s². The car moves forward steadily, covering equal distance every second.

Slope = Acceleration (a = Δv / Δt): Flat horizontal line = 0 m/s²
